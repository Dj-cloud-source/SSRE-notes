# 系统日志管理



> 系统日志对管理员来说挺重要的 



$Linux系统日志是排查故障、监控系统状态、审计安全事件的核心依据------无论是服务器宕机、应用报错，还是黑客暴力破解，都会在日志中留下痕迹。$



## 存放地址

日志存放在 `/var/log` 



![image-20260305162308827](C:\Users\25242\AppData\Roaming\Typora\typora-user-images\image-20260305162308827.png)



## 使用技巧

日志中内容非常多，有必要使用==`grep` `awk`== 等过滤工具来查看其中的内容

```bash
cat  /var/log/messages  |grep ens160
```

日志包含 “时间戳，主机名，进程名[PID]，事件详细”

## 远程备份日志

远程管理日志，防止日志被删



两台虚拟机，先不用 MobaXterm

1. 都关闭防火墙

```bash
systemctl stop firewalld
```



2. server1

```bash
vim /etc/rsyslog.conf

……

:msg,contains,"sshd" @server2的ip:514
```

3. 重启服务

```bash
systemctl restart rsyslog
```





4. server2

```bash
vim /etc/rsyslog.conf

……

$ModLoad imudp
$UDPServerRun 514

$ModLoad imtcp
$InputTCPServerRun 514

:msg,contains,"sshd" /var/log/remote_ssh.log 
```

```bash
systemctl restart rsyslog
```



用 MobaXterm 连接

5. 在server2上检查有没有日志发送过来

```bash
tail -f /var/log/remote_ssh.log
```

## 日志轮转



$记录的日志会持续增长，若不及时处理，就会占满磁盘，难以查阅，影响效率$



 `logrotate` 

我们可以删除最旧的日志文件，以节省空间

### 全局默认规则

全局默认规则，所有日志轮转都会继承这里面的配置

```bash
cat /etc/logrotate
```
