## 命令行

```bash
vim /etc/NetworkManager/system-connections/ens160.nmconnection 
```

```bash
[ipv4]
method=manual
address1=192.168.60.129/24,网关地址
dns=114.114.114.114;114.114.115.115;
```

修改完配置文件后需要重启才能生效

```bash
 systemctl restart NetworkManager
```



> `ifdown` 工具下载:  `yum install NetworkManager-initscripts-updown.noarch` 




>  服务器使用  `systemd-networkd`  







`nmcli`  命令 

`nmcli device` 查看网卡[接口]( '网络接口是 Linux 系统与外部网络通信的“桥梁”，有物理接口（如网卡）和虚拟接口（如隧道、桥接接口） ')  状态

`nmcli connection` 查看[链接信息]( ' `nmcli` 是链接了物理网卡，用 `nmcli` 编辑就直接写入网卡') 



`nmcli con mod` 配置网络信息

```bash
nmcli con mod "ens160" ipv4.addresses 192.168.60.129/24 ipv4.gateway 192.168.60.1 ipv4.dns "8.8.8.8" ipv4.method manual
```
