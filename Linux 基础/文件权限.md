# 文件权限管理



## 前言：

​	$在Linux中，需要有对应的权限，才能对文件执行操作。$

​	$normally，一个文件只能属于一个用户和组。如果其他用户想操作$
​	$这个文件，可以将这个用户加入到具备权限的group中。$

​	$当然，一个用户可以同时归属多个组$

---



先使用 `ll` 命令来看看

```bash
[root@localhost ~]# ll
total 4
-rw-------. 1 root root 907 Jan 26 10:46 anaconda-ks.cfg

```

第一位 `-` 是文件类型

后面是 **拥有者（user）**（属主） 、**群组（group）** 、**其他用户（others）** 所拥有的权限

Linux文件权限类型包括 `r` （read）、 `w` （write）、`x` (execute*执行*)  

--->`d` `rwx` `rwx` `rwx` 



-------





## 1. 修改文件拥有者（属主）



* 使用 **`chown`**  命令 (change owner)



```bash
chown destintion_group  file
```



修改属主和属组（可以同时修改，也可以单独修改）

```bash
chown owner:group  file/directory
……
chown owner:group -R  directory
```

`-R` 递归（同时、一起）修改该文件夹下的所有文件





## 2. 修改文件权限



* 使用 **`chmod`**  (change mode) 命令来修改文件权限

$上面说到有属主，属组，其他用户（组），$
`chmod` $可以设置他们的权限$



### 法1：权限设定字符串



```bash
chmod u+r    file_name/directory
```

| user/group/others | 选项 | 权限 | 含义 |
| :---------------: | :--: | :--: | ----------------- |
| u | + | r |为拥有者添加 **读** 权限|
| g | - | w |为属组添加 **写** 权限|
| o | + | x |为其他用户（组）添加**执行** 权限|
| a | + | r |为三者都添加 **读** 权限|







### 法2：八进制语法



| 数字  | 权限       | 权限 |
| ----- | ---------- | ---- |
| 7     | 读+写+执行 | rwx  |
| 6     | 读+写      | rw-  |
| 5     | 读+执行    | r-x  |
| ==4== | 只读       | r--  |
| 3     | 写+执行    | -wx  |
| ==2== | 只写       | -w-  |
| ==1== | 只执行     | --x  |
| 0     | 无         | ---  |

> ==1==执行   ==2==写    ==4==读
>
> “ 7 = 4 + 2 + 1 ”





```bash
[root@localhost ~]# ll

drwxr-xr-x. 2 root   root   6 Jan 29 18:20 dir

chmod 077 dir

d---rwxrwx. 2 root   root   6 Jan 29 18:20 dir

```





### 法3：个性化定制



```bash
 chmod u=rwx,g=---,o=r-- dir

drwx---r--. 2 root   root   6 Jan 29 18:20 dir

chmod g=rwx  dir

drwxrwxr--. 2 root   root   6 Jan 29 18:20 dir
```





## 3. UMASK值

作用：

*取消对应权限，影响创建文件和目录时的默认权限*



`umask -S` 查看创建新东西时可用的权限



```bash
[root@localhost ~]# ll
drwxr-xr-x. 2 root   root   6 Jan 29 19:19 dir3
……
umask 070
mkdir dir2
[root@localhost ~]# ll
drwx---rwx. 2 root   root   6 Jan 29 19:17 dir2
```

> 可以看见中间的已经 unable 了



## 4. ACL权限

$ACL是Access Control List（访问控制列表）的缩写$



> 有时候想单独给某个用户赋予权限，但直接修改ugo的权限又会引发其他问题（如其他用户意外获得了权限），由此，需要一个更灵活的，权限赋予方式，ACL由此而生



### `getfacl` 

* 用 `getfacl` 查看权限列表详细内容

```bash
getfacl  file_name
```



### `setfacl`

* 用 `setfacl` 来更精确地设置文件权限



```bash
setfacl -m u:user1:rx  dir_name
……
setfacl -x u:user1     dir_name
……
setfacl -m g:worker2:rwx dir_name
```



`-m` :更改acl权限

`-x` :删除acl权限

`-R` :递归操作子目录
