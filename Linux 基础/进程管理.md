# 进程管理



## ***小试牛刀***



$在Linux中，进程是正在运行的程序$

> 进程（Process）是资源分配和任务执行的基本单元。无论是排查系统故障、优化性能，还是监控服务状态，掌握进程管理工具都是必备技能。



可以用 `ps` 命令显示当前正在执行的进程

```bash
[root@Linuxtest ~]# ps

    PID TTY          TIME CMD
  79134 pts/2    00:00:00 bash
 118634 pts/2    00:00:00 ps
```

>  当然，我们作为管理，需要看的是更详细的信息



使用 `ps aux` 查看更详细的内容

```bash
[root@Linuxtest ~]# ps aux
USER         PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root           1  0.0  0.8 172340 15732 ?        Ss   14:19   0:02 /usr/lib/systemd/systemd 
root           2  0.0  0.0      0     0 ?        S    14:19   0:00 [kthreadd]
……
```

> 这就可以看到,系统进程的详细信息

##  `ps` 命令



### 什么是 `ps` 命令？

*  `ps` 全称 $Process Status$  （进程状态）

它是截取当前时刻的进程状态，用于查看静态信息





### 为什么是 `ps aux` 命令

​	option：

​		`-a`  : (all) [列出所有用户的进程]( '监控多用户系统时,可以看到其他用户的进程是否异常占用资源')

​		`-u`  : (user-oriented) 显示用户[设备]( '查看CPU使用率等资源占用指标，可明显看出进程对系统的影响')相关的详细信息

​		`-x`  :  [显示后台服务]( '这类进程通常是脱离终端运行的后台任务，如systemd、Nginx、sshd等守护进程')[进程]( 'Linux 系统中大量关键进程（如数据库、Web 服务器）以守护进程形式运行，无终端关联。`x` 选项确保这些进程不会被遗漏')



三个选项结合，可以查看系统中，**所有活跃进程的完整信息** ，是监控和调优的强大工具



### 显示字段详解

|                          字段                          |                             说明                             |
| :----------------------------------------------------: | :----------------------------------------------------------: |
|                          USER                          |                         进程所属用户                         |
|                          PID                           |           标识符，用于操作进程（如 `kill` +`PID` )           |
|                          %CPU                          |                       占用CPU的百分比                        |
|                          %MEM                          |                     占用物理内存的百分比                     |
| VSZ([KB]( ' `VSZ`参考价值低于 `RSS`（物理内存占用）')) |            占用虚拟内存大小(Virtual Memory size)             |
|                        RSS(KB)                         |              占用的物理内存(Resident Set Size)               |
|                          TTY                           | `?` 表示[守护进程]( '指在后台运行的进程,它不与任何终端关联,通常在系统启动时自动启动,并在系统关闭时终止。守护进程的主要功能是提供持续运行的服务,如网络服务、系统日志记录、定时任务执行等.且不能直接和用户交互 ') ，`pts/0` 表示伪终端（如 SSH 连接） |
|                          STAT                          |                    进程状态。（有许多种）                    |
|                         START                          |                           启动时间                           |
|                          TIME                          |              计算占用CPU的实际时间，非运行时长               |
|                        COMMAND                         |                      启动此进程的命令行                      |



####  关于`STAT` 的解析

| 状态码 |            含义            |                                      |
| :----: | :------------------------: | :----------------------------------- |
|   S    |    Sleeping(可中断睡眠)    | 等待事件完成（如 I/O），可被信号唤醒 |
|   s    | session leader(会话领导者) | 如登录 shell 进程                    |
|  $I$   |         idle(空闲)         | Idle kernel thread                   |
|   <    |        高优先级进程        | 被`nice` 提高优先级                  |
|   N    |          低优先级          | 被`nice` 降低优先级                  |
|   +    |          前台进程          | 在终端中直接运行的程序（如 `ls` )    |
|   R    |          Running           | 运行中                               |
|   Z    |      Zombie(僵尸进程)      | 进程已终止，但父进程没有回收其资源   |
|  $l$   |         多线程进程         | 如Java程序                           |



### 高级过滤和排序技巧



#### 1. 使用 `--sort` 按字段排序

​	`-` + `字段` 是从大到小排序

​	`-` ` 字段1` `,` `-` `字段2`  先按字段1排序，再按字段2排序

```bash
ps aux --sort -%cpu
……
ps aux --sort -vsz
```



#### 2. 使用 `grep` 过滤

```bash
ps aux |grep sshd
```

> 用正则表达式寻找特定用户  `grep ^user_name` 



#### 3. 使用`pgrep` 快速寻找 PID

* `pgrep` 是`ps` + `grep` 的简化工具，直接输出匹配进的PID

```bash
pgrep ssh
……
pgrep nginx
```

#### 4. `head` 工具

​	`-n` + `行数`

```bash
…… |head -n 6 
```

> `tail` 命令同理，不多赘述



#### 5. 使用 `pstree` 命令

​	`pstree`  

​	`pstree` + `-p` 显示PID

> `pstree` 命令以树状结构显示进程的层次关系。它使得你能够更清晰地了解进程之间的父子关系。



#### 6. `htop` 

> `htop` 提供比 `top` 更友好的界面和更多的功能



```bash
yum install epel-release
……
yum install htop
……
htop
```







## `top` 命令



![image-20260201113532939](image-20260201113532939.png)

* `top` 命令，可以**实时、动态**地，查看系统资源和进程状态

​	`-p` + `PID` 查看指定PID的信息

​	`-u` + `用户` 查看指定用户

​	`-d` + `秒数` 指定更新速度



进入`top` 的交互模式后，可以使用快捷键进行排序

| 快捷键      | 功能                            |
| :---------- | ------------------------------- |
| `q`         | 退出交互模式                    |
| `z`         | 彩色                            |
| `M`         | 按内存使用率排序                |
| `P`（大写） | 按CPU使用率排序                 |
| 空格        | 立即刷新                        |
| `t`         | 切换显示方式，显示进程和CPU信息 |
| m           | 切换显示方式                    |
|             |                                 |





## `kill` 命令

* 使用 `kill` 命令**结束进程**

​	`kill` + `PID` 向指定进程发送默认的终止信号



| 编号  | 作用     |
| ----- | -------- |
| `-20` | 停止     |
| `-18` | 继续     |
| `-9`  | 强制终止 |



> 请谨慎使用 `kill -9`，因为它会立即终止进程，可能导致数据丢失或损坏。



`pkill` 命令

`pkill` 命令会**结束所有匹配的进程**。*除此之外，pkill 还有一个更重要的功能，即按照终端号来踢出用户登录。*



**谨慎操作高权限进程**：
杀死进程前务必确认 PID 正确性，避免误杀关键系统进程（如 `systemd`、`sshd`）

## `job` 命令

* 首先是把任务放到后台
	* 使用 `  &` 可以让任务在后台执行
	*  `nohup`  [也可以]( https://ncloud.eagleslab.com/Linux%E5%9F%BA%E7%A1%80/%E8%BF%9B%E7%A8%8B%E7%AE%A1%E7%90%86.html#nohup ' no hang up 只要服务器不关机，即使我们退出登录，任务依然能够在后台工作')

```bash
ping qq.com >/dev/null &
```





*   `job`  命令可以查看被放入后台的命令
	* `-l` 查看PID

```bash
[root@Linuxtest ~]# jobs -l
[1]+  1314 Running       ping baidu.com > /dev/null &

```





* 把任务放到前台运行

​	`fg` + `工作号` 

* 后台任务回复到后台运行

​	`bg` + `工作号`
