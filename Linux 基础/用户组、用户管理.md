# 用户组和用户管理



----

首先可以查看 *用户和组的对应关系* 

```bash
cat /etc/group
```

```bash
root:x:0:
bin:x:1:
……
```

```bash
组 : 密码  : id : 组内用户
```





## *用户组*

### 1. 添加用户组

```bash
groupadd -g  6666	groupname
```

>  `-g`  : 指定新建用户组id 





### 2. 修改用户组

```bash
groupmod -n 新组名  旧组名
```

>  `-n`  : 改名为 *新组名*



### 3. 删除用户组

```bash
groupdel  group_name
```









## 用户管理



### 1. 添加用户

```bash
useradd user_name
```



```bash
useradd -g group  user_name
```

> 添加到指定的用户组



```bash
useradd -d /home/dir user_name
```

> 为新用户指定home目录



### 2. 删除用户

```bash
userdel -r user_name
```



### 3. 切换用户

* **`su`**命令

```bash
su - user_name
```





### 4. 修改用户设置

* `usermod`  命令



```bash
usermod -u 6666 user03
```

> `-u`  : 修改用户 id
>
> `-g`  : 修改所属群组



### 5. 管理组成员

*  `gpasswd`  管理工具

```bash
gpasswd -a user  group
```

> `-a`  : 添加用户到组
>
> `-d`  ：删除组内用户

## 用户密码管理



### root用户修改密码

*  用  **`passwd`** 命令修改密码。（但Linux不给改成太简单的密码）

```bash
passwd  user_name
……
New password:
Retype new password:
```

> `-S  :  (State)查看密码状态





### 普通用户修改密码

-->$上面的操作是在root用户下完成的，但普通用户不能自己改密码$

$所以我们还要给普通用户解锁一下。$

> `-u`  :  在 *root用户* 下**解锁**普通账户修改密码的权限
>
> `-l`  :  **锁定**密码	
>
> `-d`  :  **删除**密码

```bash
[root@localhost ~]# passwd -u user_name
……
su - user_name
……
[usertest@localhost root]$ passwd 
Current password: 
New password:
New password: 
```

$如果原来密码不对，会出现报错$

```bash
passwd: Authentication token manipulation error
```
