# 计划任务



$计划任务（Scheduled Task）是自动化运维的核心工具之一。它允许用户或系统管理员预先设定脚本、命令或程序在特定时间、周期性$ $执行，从而实现诸如日志清理、数据备份、系统监控、软件更新等重复性工作的自动化。这不仅减少了人工操作成本，还能确保任务在$ $精确时间点执行，提升系统可靠性。$





## 单次调度执行 `at`

安装

```bash
yum install -y at 
systemctl start atd
```



用法

*  `at` + `时间` 

```bash
at now +5min 
at 11:20 AM
at noon +4 days 
……
```

```bash
at now +5min
at> touch /root/file2
```

> Ctrl + D 结束编辑



*  `at -f`  + `包含指令的文件`  执行指定文件
*  `at -c`  按序号查看
*  `atrm`  通过序号删除



 `at -l`  查看待执行任务

## 循环调度执行 `cron` 

$Cron 是 Linux 中最经典且应用最广泛的计划任务工具，它非常适合定期运行脚本、备份数据、清理临时文件等一系列重复性任务。$



 `cron` 基本用法

*  `crontab` +
	*  `-l`  列出当前用户所有计划任务
	*  `-e`  编辑当前用户的计划任务
	*  `-r`  删除所有任务（慎用）
	*  管理员可通过 `crontab -u <用户名> -e` 编辑其他用户的任务（需 root 权限）。





用

```bash
crontab -e
```

编辑计划任务







cron 任务的格式为 五行时间字段 + 命令



`*`  表示任意值； `*/数字` 表示每几分钟；`a,b,c` 枚举值（每月的 a 日，b 日，c 日执行一次）；

`a-b`：a 到 b 的范围；`0`  表示整点

星期和日同时存在，那么就是或的关系

```bash
分 时 日 月 星期   命令
*  *  *  *  *   


```
