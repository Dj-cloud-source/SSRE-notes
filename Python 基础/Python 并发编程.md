





# 并发编程



## 前言

并发编程不是同时做很多件事

而是让CPU别等，**快速切换不同到的任务** 

不让程序因为一个任务阻塞，就把所有任务全拖累，

并发 ≠ 并行啦（—：



前面学 socket 的时候，一次只能服务一个客户端，如果一直卡着等一个客户端，那别的客户端就可能被拖住，

所以自然而然的引出并发的需求





## 先简单介绍一些概念

1. 进程：正在运行的程序实例。
	* 进程之间一般相对独立，互不影响（也就是说进程可以 “同时工作”。
	* 比如打开微信、浏览器、它们都可以看成不同进程

​		



2. 线程：进程内部更小的执行单位
	* 一个进程里可以有多个线程。比如一个程序里，可以一边下载文件，一边播放视频



3. 协程：在单线程里运行；是比线程更轻的一种并发方式，适合大量等待任务。
	* 协程又叫 异步 I/O
