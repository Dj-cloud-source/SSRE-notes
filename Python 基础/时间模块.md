##  `time` 模块





### 时间戳

时间戳，是从1970年01月01日，00时00分00秒起到现在的总秒数

```python
import time

print(time.time())
```

输出的就是“从1970到现在的秒数”







### 暂停程序

 `time.sleep(秒数) ` 

让程序暂停几秒

常用于

* 爬虫限速
* 定时测试
* 模拟等待

### ==格式化时间== 

 `time.strftime('format')` 

作用：把结构化时间对象格式化成好看的字符串

```python
now = time.localtime()
result_now = time.strftime('%Y-%m-%d %H:%M:%S',now)

print(result_now)
print(type(result_now))

result_now1 = time.strftime('%Z %X',now)
print(result_now1)
```

```python
2026-03-29 21:37:12
<class 'str'>
中国标准时间 21:37:12
```



最常用： ==`"%Y-%m-%d %H:%M:%S"`== 



 `format` :

* `%Y` ：四位数年份

* `%y` ：两位数年份

* `%m` ：月份（和 `%M` 分钟数 区别开）

* `%d` ：日

* `%D` ：直接输出 `月 / 日 / 年` 

* `%h` ：英文月份

​	

* `%H` ：二十四小时
* `%I` ：十二小时
* `%M` ：分钟
* `%S` ：秒数（大写）	



* `%Z` :当前时区（大写）
* `%X` ：本地时间（大写）



---



将格式化时间转换为结构化时间

```python

s_now = time.strptime(t_now,'%Y-%m-%d %H:%M:%S')
```

##  `datetime` 模块



### 获取当前时间

```python
import datetime

now = datetime.datetime.now()
print(now)
```

```python
2026-03-31 15:58:17.708430
```

> 第一个是模块名，第二个是类名，第三个是方法。别搞混





### 取出时间对象

```python
print(now.day)
print(now.year)
print(now.second)
```

```python
31
2026
30
```





### 格式化时间

```python
print(now.strftime('%y-%m-%d %H:%M:%S '))
```



### 时间加减

* `timedelta()` 

```python
future = now +datetime.timedelta(days=6)
future1 = now + datetime.timedelta(hours=8)
print(future)
```

```python
2026-04-06 16:27:45.242904
2026-04-01 00:27:45.242904
```



### 计算时间差

将时间对象相减

```python
diff = future - future1
print(diff)
print(diff.seconds)
```

```python
5 days, 16:00:00
57600
```
